## 🌟 Overview

This repository contains the source code for a developer portfolio built with semantic **HTML5** and clean, modular **CSS3**. It features a desktop-first dual-column sticky layout (`sidebar` + `main content panels`), smooth CSS transitions, custom hover effects, and a cohesive dark mode theme accented with gold highlights (`#ffd700`).

## 📂 File Structure

```
├── index.html          # Main HTML document containing semantic structure & layout content
└── style1_2.css        # Comprehensive stylesheet handling theme colors, grids, flexbox, and responsiveness

```

## ✨ Key Features

* **Sticky Sidebar Profile:** Keeps developer branding, bio, and contact information permanently in view on desktop viewports.

* **Auto-Fit Skills Matrix:** Responsive CSS grid layout highlighting core technologies with interactive hover zoom effects.

* **Education Timeline:** Structured node-based timeline design tracing academic credentials.

* **Project Showcase Cards:** Dual-column grid presenting key projects with embedded tags and hover elevation.

* **Fully Responsive Design:** Seamlessly adapts from a 2-column desktop layout to a single-column stack on tablets and mobile devices.

## 🛠️ Built With

* **HTML5** — Semantic structure and document routing.

* **CSS3** — Advanced styling, CSS Grid, Flexbox, custom media queries, and animations.
